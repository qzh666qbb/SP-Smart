## 角色设计

### 1. 管理员（PC 管理后台）

管理员主要通过 PC 后台进行系统维护和批量操作，拥有以下权限：

* 学员、教师、家长账号管理
* 家长与学员绑定
* 课程管理
* 班级管理
* 排课、调课和取消课程
* 课程签到和完成课程
* 课时充值、扣减、补录和修正
* Excel 批量导入学员、教师、排课和体测数据
* 体测模板配置
* 体测数据录入和管理
* 体测报告生成、重新生成和删除
* 课时、课程和体测报表导出
* 操作日志查询


---

### 2. 教师（微信小程序）

教师除了完成日常教学操作外，也可以直接处理课程、排课、课时和体测管理工作。

教师拥有以下权限：

* 查看全部或本人负责的学员
* 新增和修改学员基本信息
* 查看本人及其他教师的课表
* 课程管理
* 班级管理
* 新增排课、修改排课、调课和取消课程
* 课程签到
* 提交上课完成记录
* 登记请假、缺勤和取消状态
* 课时充值、扣减、补录和调整
* 查看学员课时账户和课时流水
* 体测模板配置
* 录入和修改学员体测数据
* 生成、重新生成和查看体测报告
* Excel 批量导入学员、排课和体测数据
* 导出课时、课程和体测报表

管理员和教师在以下模块中的权限一致：

```text
课程管理
排课管理
课时调整
体测模板与体测报告
Excel 导入导出
```

管理员和教师的主要区别不在业务操作权限，而在于：

```text
管理员：
负责账号维护、教师管理、家长管理和系统级操作日志查询。

教师：
负责日常教学和业务数据处理，不负责管理员账号和系统配置管理。
```

---

### 3. 家长（微信小程序）

家长只能查看与绑定孩子相关的数据：

* 查看孩子课表
* 查看课程详情
* 查看课程签到和完成状态
* 查看剩余课时
* 查看课时消费流水
* 查看历史上课记录
* 查看体测历史数据
* 查看、保存和分享体测报告
* 一个家长可以绑定多个孩子

家长不能修改课程、课时、体测和学员信息。

## 权限设计原则

由于管理员和教师在主要业务模块中的权限基本一致，因此第一版不需要设计复杂的 RBAC 权限系统。

用户表可以继续使用简单角色字段：

```text
user
- id
- username
- password_hash
- role
- phone
- status
- created_at
- updated_at
```

角色值：

```text
ADMIN
TEACHER
PARENT
```

业务接口可以按照访问角色划分为三类。

### 管理员专属接口

主要用于账号和系统维护：

```text
/api/admin/teacher/**
/api/admin/parent/**
/api/admin/account/**
/api/admin/operation-log/**
```

### 管理员和教师共用接口

主要用于日常业务处理：

```text
/api/business/student/**
/api/business/course/**
/api/business/class/**
/api/business/schedule/**
/api/business/lesson/**
/api/business/hour/**
/api/business/physical-test/**
/api/business/report/**
/api/business/import/**
/api/business/export/**
```

接口允许：

```text
ADMIN
TEACHER
```

两个角色访问。

### 家长接口

只能访问绑定孩子的数据：

```text
/api/parent/children/**
/api/parent/schedule/**
/api/parent/hour/**
/api/parent/lesson/**
/api/parent/report/**
```

后端必须根据家长与学员绑定关系进行数据过滤，不能仅依靠前端隐藏页面。

## 课时调整权限设计

管理员和教师都可以调整课时，但必须保留完整流水，不能直接覆盖剩余课时。

```text
hour_transaction
- id
- student_id
- change_amount
- before_balance
- after_balance
- transaction_type
- reason
- related_lesson_id
- operator_id
- operator_role
- created_at
```

课时变动类型：

```text
RECHARGE
课时充值

CONSUME
上课扣减

REFUND
课时退回

ADJUST
手动调整

ROLLBACK
撤销扣减

IMPORT
历史数据导入
```

教师或管理员手动调整课时时，应强制填写调整原因：

```text
调整前课时：12
调整数量：+2
调整后课时：14
调整原因：补录历史购买课时
操作人：张老师
```

---

## 关键操作控制

虽然教师拥有较高业务权限，但以下安全机制仍需保留：

* 课时调整原因必填
* 删除课程前二次确认
* 取消已完成课程时生成反向课时流水
* 已完成课程不得重复扣减课时
* Excel 导入前展示预校验结果
* Excel 导入记录导入人和导入时间
* 体测报告重新生成时保留历史版本
* 学员、课程和体测数据采用软删除
* 教师只能查看本人操作日志
* 管理员可以查看全部操作日志

## Excel 导入导出权限

管理员和教师权限一致，都可以进行以下操作：

### 导入

* 学员数据导入
* 课程数据导入
* 班级成员导入
* 排课计划导入
* 历史课时导入
* 体测数据导入

### 导出

* 学员名单
* 教师名单
* 课程表
* 排课计划
* 上课记录
* 课时流水
* 课时余额汇总
* 体测原始数据
* 体测结果汇总
* 体测报告列表

教师在小程序中选择微信文件上传 Excel，后端负责解析和校验；导出的文件可以通过小程序下载或发送至微信文件。

## 最终角色关系

```text
管理员 PC 后台
    ├── 管理教师和家长账号
    ├── 管理学员
    ├── 管理课程和班级
    ├── 排课与调课
    ├── 管理课时
    ├── 管理体测和报告
    ├── Excel 导入导出
    └── 查看全部操作日志

教师微信小程序
    ├── 管理学员
    ├── 管理课程和班级
    ├── 排课与调课
    ├── 完成课程和签到
    ├── 调整课时
    ├── 管理体测和报告
    ├── Excel 导入导出
    └── 查看本人操作记录

家长微信小程序
    └── 查看绑定孩子的课表、课时、上课记录和体测报告
```

因此，系统中的管理员更接近“系统账号维护人员”，教师则是“业务操作人员”。两者在核心教学业务模块中权限相同，仅在账号管理和全局操作日志方面存在区别。
